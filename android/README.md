# ShaGa IPTV Player — Android (TV + phones)

Универсальный плеер M3U-плейлистов. Сам каналов не содержит.
Одно приложение для Android TV / Google TV (пульт) и телефонов/планшетов (сенсор).
Правила поведения — в `SPEC.md` в корне репозитория; до паритета с Roku и LG версии Android идут как `0.x.y`.

## Версия 0.2.0 — главный экран и просмотр
- Левая колонка: `> Изменить ссылку`, `> Настройки`, `Все каналы (N)`, группы плейлиста.
- Колонка каналов: номер, логотип, название. Третья колонка (широкий экран): канал и его состояние.
- Видео идёт под полупрозрачным списком; на телефоне вертикально — прямоугольник вверху.
- OK на канале запускает его, повторный OK — полный экран. На полном экране вверх/вниз и CH+/− переключают каналы категории (направление — в Настройках), OK показывает плашку.
- Back по шагам: полный экран → каналы → группы → остановить видео → окно «Закрыть?».
- Пульт обрабатывается в `MainActivity` и `Nav.kt`; экран фокусом ввода не пользуется.

## Версия 0.3.0 — поиск, избранное, меню, язык, настройки
- Служебные строки: `> Поиск`, `> Изменить ссылку`, `> Язык`, `> Настройки`; категории `Поиск: … (N)`, `Избранное (N)`, `Все каналы (N)`, группы.
- Поиск по правилам SPEC (регистр, ё=е, акценты, латиница находит кириллицу).
- Избранное по названиям каналов, до 200. Контекстное меню канала — долгое OK или долгое нажатие: в избранное / убрать, перейти в группу канала.
- Язык: автоматически / English / Español / Русский.
- Настройки: переключение каналов, о приложении (политика, поддержка), закрыть приложение.
- Номер канала цифрами (до 4 цифр, пауза 1,6 с или OK) — канал включается на весь экран.
- Телефон, полный экран: жест вверх — следующий канал, вниз — предыдущий.
- OK срабатывает при отпускании кнопки (чтобы отличать долгое нажатие).

## Версия 0.4.0 — защита групп, плейлисты, свои окна
- Режимы групп «Показана / По PIN-коду / Скрыта», отметка «Группа 18+» (правила SPEC, раздел 7, «Каналы групп 18+»), PIN-код (sha256), мастер-код, флажок «PIN введён» на одну группу (сброс через 10 минут, при включении канала другой группы, при сворачивании).
- До 5 плейлистов: окно «Плейлисты» (открыть, изменить ссылку, удалить), копия каждого плейлиста (`pl_<id>.m3u`), показ из копии сразу, свежий список в фоне.
- Автозапуск последнего канала (если его группа «Показана» и без отметки 18+).
- Поиск каналов с масками `*` и `?` (как в Roku/LG 1.4.0).
- 1.4.1: OK на полном экране сворачивает к спискам, отметка «где играет», возврат курсора к играющей строке.
- Свои окна (меню, вопросы, клавиатура PIN-кода) и экран Настроек: Плейлист, Обновить список каналов, Группы, PIN-код, Переключение каналов, Журнал, О приложении, Закрыть приложение. Ввод ссылки и поиска — системное окно (нужна экранная клавиатура).
- Служебные строки левой колонки: `> Поиск`, `> Плейлисты`, `> Язык`, `> Настройки`.

## Версия 0.5.0 — программа передач, архив, файлы
- Программа передач (XMLTV): поток байтов, gzip, кодировка из `<?xml encoding>`, окно −24…+24 ч, короткое описание 200 символов + место в файле, полное — через HTTP Range. Копия `epg.bin`: моложе 24 ч показывается сразу, обновление раз в 12 ч в фоне, при ошибке — повтор через 30 мин. Первая загрузка показывает разобранное каждые 20 МБ.
- Строка канала: передача и полоска прогресса. Третья колонка: «Сейчас» / «Далее» или причина, почему программы нет. Вправо из каналов — программа канала (OK: эфир / архив / описание; долгое OK или INFO — меню).
- Поиск: каналы, передачи, описания (до 300 ближайших, «вчера/сегодня/завтра», цвет по времени).
- Архив: Настройки → Плейлист → Архив (Из плейлиста / shift / flussonic / xc / Выключен) и глубина; влево/вправо ±60 с, перемотка ±5 мин, свои часы позиции; «Смотреть с начала» в меню канала.
- Файлы: влево/вправо ±10 с, перемотка ±30 с, Play/Pause; конец файла — «Конец», а не ошибка.

Нет (план общей 1.5.0): «Загрузить ещё» в программе, глубина поиска, автоперезапуск архива, следующая передача архива.

## Сборка
Собирает GitHub Actions (`.github/workflows/android.yml`) при каждом изменении в `android/`.
Готовый APK: вкладка **Actions** → последний запуск → **Artifacts** → `shaga-iptv-player-<версия>-android`.
Android Studio не нужна, но проект в ней открывается (папка `android/`).

Версии: Gradle 8.13, Android Gradle Plugin 8.11.1, Kotlin 2.2.20, Compose BOM 2025.08.00, Media3 1.8.0, Coil 3.3.0. Приложению включена большая куча памяти (largeHeap) для программы передач.
Android: минимум 7.0 (API 24), цель — 16 (API 36).

## Установка (adb из Android SDK Platform-Tools)
    adb connect <ip-устройства>:5555
    adb install -r shaga-iptv-player-<версия>-android.apk
    adb shell am start -n com.shaga.player/.MainActivity

## Журнал
    adb logcat -d -s ShaGa:V AndroidRuntime:E
Первая строка — название и версия. Теги как в Roku: APP, KEY, PLAY, ERR, LOAD, UI.
Ключи доступа в ссылках маскируются (`Mask.kt`), цифровые кнопки не пишутся.

## Структура
    app/build.gradle.kts            версия, уровни Android, библиотеки
    app/debug.keystore              тестовый ключ подписи (не секретный, не для Google Play)
    app/src/main/AndroidManifest.xml
    app/src/main/res/               название, тема, баннер для ТВ 320x180, значок
    app/src/main/java/com/shaga/player/
        Config.kt           настройки (тайм-ауты, User-Agent)
        Strings.kt          строки EN/ES/RU
        TextUtil.kt         ссылки: очистка, проверка, имя плейлиста; маски поиска
        M3u.kt              разбор плейлиста
        PlaylistLoader.kt   загрузка плейлиста по ссылке
        Storage.kt          сохранённые настройки (JSON, схема как в Roku и LG), копии плейлистов
        Mask.kt, AppLog.kt  журнал и маскировка ключей
        Epg.kt              программа передач: разбор XMLTV, копия, загрузка, полное описание
        Catchup.kt          ссылки архива (shift / append / default / flussonic / xc)
        Groups.kt           защита групп: режимы, отметка 18+, PIN-код, мастер-код, флажок «PIN введён»
        Nav.kt              логика главного экрана: строки левой колонки, курсор, полный экран, Back по шагам
        Overlays.kt         свои окна: меню / вопрос, клавиатура PIN-кода, страницы Настроек
        Playback.kt         плеер Media3 (ExoPlayer), один на всё приложение
        Ui.kt               экраны (Compose)
        MainActivity.kt     окно приложения, кнопки пульта, окна, плейлисты, PIN, избранное, Настройки

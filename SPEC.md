# ShaGa IPTV Player — общая спецификация (Roku + LG webOS)

Единый источник правил для обеих версий. Любое изменение поведения сначала вносится сюда, потом в код обеих платформ.
Состояние на 8 ноября 2026 г.: **Roku 1.2.0**, **LG 0.4.0**.
Пометки: **[Roku]** / **[LG]** — касается одной платформы; **❓** — открытый вопрос (раздел 12).

## 1. Назначение и магазины
- Название на обеих платформах: **ShaGa IPTV Player**.
- Бесплатный плеер собственных плейлистов M3U/M3U8 пользователя. В приложении нет каналов, демо-плейлистов и ссылок на провайдеров.
- Описание в магазинах: «приложение не содержит каналов; пользователь добавляет собственный плейлист из законных источников». Скриншоты — без логотипов телеканалов и групп 18+.
- Тестовый плейлист для проверяющих — отдельная страница (GitHub Pages), только легальные открытые потоки, без 18+; даётся в заметках к отправке.
- Языки интерфейса: EN, ES, RU; по умолчанию язык системы, иначе EN; первый пункт выбора — «Автоматически (язык системы)».
- Политика конфиденциальности и контакт поддержки — на GitHub Pages и пунктом «О приложении» в Настройках (обе платформы).

## 2. Экраны
1. **Приветствие** (нет плейлистов): текст «в приложении нет каналов…», OK → ввод ссылки. [Roku] подсказка про QR-код клавиатуры для ввода с телефона.
2. **Главный экран — три колонки:**
   - левая: `> Поиск`, `> Плейлисты`, `> Язык`, `> Настройки`; затем `Поиск: <запрос> (N)` (если был поиск), `Избранное (N)`, `Все каналы (N)`, группы плейлиста `Название (N)`; группа «По PIN» — `Название [PIN]` без счётчика;
   - средняя: каналы, строка в два этажа — номер (колонка под 4 цифры, вправо) · логотип · название; под ним текущая передача мельче и тонкая полоска прогресса (нет программы — пусто, полоска скрыта);
   - правая: передача и программа (см. раздел 9).
   - Заголовки: над группами — выделенная группа; над каналами — «Сейчас смотрите: …», если играет видео, иначе выделенный канал; над третьей колонкой — передача на играющем канале, иначе на выделенном (нет программы — название канала).
   - **Видео:** [Roku] миниатюра 580×326 в правом верхнем углу; [LG] на весь экран под полупрозрачным списком. *Единственное запланированное различие.*
3. **Полный экран** — плашка: номер, название, группа, передача и время; скрывается через 4 с.

## 3. Управление
- OK на канале — запустить; повторный OK на играющем — полный экран.
- Влево/вправо — между колонками.
- Шаг на одну строку во всех вертикальных списках циклический (группы, каналы, настройки, вертикальные меню). Листание страницами и колесо Magic Remote останавливаются у краёв. Горизонтальные кнопки окон и PIN-клавиатура — без зацикливания. [Roku] кнопки внутри системных окон Roku зациклить нельзя.
- **Back по шагам:** полный экран → список (фокус на каналах) → группы → остановить видео → окно выхода (курсор на «Выйти»; Back в окне — обратно в группы). «Закрыть приложение» — последний пункт Настроек.
- Полный экран: вверх/вниз — переключение каналов текущей категории по настройке «Переключение каналов»: «Как в списке» (по умолчанию, вверх → меньший номер) / «Классическое».
- Избранное: [Roku] кнопка `*` на выделенном канале; [LG] жёлтая кнопка. Настройки: [LG] синяя кнопка (дубль пункта `> Настройки`).
- [LG] набор номера канала цифрами. [Roku] нет (цифровых кнопок на пульте нет).
- Файлы (VOD): влево/вправо ±10 с, перемотка ±30 с, instant replay −15 с, Play/Pause — переключатель. [LG] если появится перемотка — нужны экранные кнопки.
- [Roku] кнопка `*` во время полноэкранного видео не используется (зарезервирована системой).

## 4. Плейлисты
- До 5 плейлистов. «Плейлисты»: список, текущий отмечен `*`, курсор сразу на текущем; `+ Добавить плейлист`, `Закрыть`. Для каждого: Открыть / Изменить ссылку / Удалить (с подтверждением).
- Имя: сайт · имя файла (если до 24 символов), без логина и пароля.
- Ввод ссылки: до 2048 символов, пробелы убираются, без схемы добавляется `https://`, проверка: http(s) и точка или двоеточие в имени сервера.
- **Новый плейлист сохраняется только после успешной загрузки**; при ошибке окно ввода остаётся с текстом ошибки. Дубликат сохранённой ссылки → открывается тот плейлист.
- При запуске открывается последний успешно загруженный. Удаление текущего: видео останавливается, открывается последний успешный из оставшихся, иначе первый; нет плейлистов — приветствие.
- Переключение плейлиста останавливает видео, сбрасывает поиск и открытую PIN-кодом группу.
- **Кэш:** разобранный плейлист хранится отдельно для каждого ([Roku] файл в `cachefs:`; [LG] IndexedDB). При запуске список показывается сразу из кэша, свежий загружается в фоне после старта видео. Удаление плейлиста удаляет кэш; при смене ссылки старый кэш не используется. Если обновить не удалось — пометка «сохранённая копия, обновить не удалось».
- Загрузка всегда мимо HTTP-кэша (иначе можно молча получить старую копию). Тайм-аут 30 с. Ошибки: сервер не ответил вовремя / ошибка сервера (HTTP-код) / не удалось подключиться / по ссылке нет M3U / в плейлисте нет каналов.
- Разбор M3U: `tvg-id`, `tvg-name`, `tvg-logo`, `group-title`, `#EXTGRP`, `#EXTVLCOPT:http-user-agent / http-referrer`, `url-tvg` / `x-tvg-url` в заголовке.

## 5. Поиск
- По части названия; без учёта регистра; ё=е; акценты не учитываются (`espana` → «España»); латиница находит кириллицу: транслит + склейка вариантов kh→h, ts→c, j→y, w→v, x→ks, q→k, ie→e, ye→e (`pervyy` → «Первый»).
- Результаты — категория `Поиск: … (N)` после служебных строк; при обновлении плейлиста пересчитываются. Только по каналам показанных групп. «Ничего не найдено» — окно.

## 6. Избранное, автозапуск
- Избранное хранится по **названиям** каналов (в ссылках ключ доступа может смениться), общее для всех плейлистов. Категория «Избранное» — перед «Все каналы».
- Последний канал (название + группа) запоминается и включается при запуске, если его группа «Показана». [Roku] только если в настройках Roku включено «Автовоспроизведение», иначе канал лишь выделяется.
- Значок загрузки поверх видео — только при буферизации дольше 0,7 с. Тайм-аут старта канала 45 с.

## 7. Группы 18+, PIN-код
- Режимы группы: **Показана / По PIN-коду / Скрыта**. Хранятся по названию группы, общие для всех плейлистов.
- Группы с признаками 18+ по умолчанию «Скрыта». Признаки (в названии группы, без учёта регистра): `18+`, `+18`, `(18)`, `xxx`, `ххх` (кириллица), `adult`, `porn`, `erotic`, `sexy`, `взросл`, `эрот`, `порн`, `для взрослых`. Каналы по названию не проверяются.
- «Все каналы», поиск, избранное, автозапуск, deep link — только группы «Показана». Группа «По PIN»: без счётчика; до ввода PIN колонка каналов просто пустая — ни названий каналов, ни передач.
- **Просмотр (флажок «PIN введён»):** OK на группе «По PIN» спрашивает PIN; верный PIN ставит флажок этой группе (флажок только у одной группы). С флажком по группе ходят свободно: каналы, передачи, переключение — без PIN. Флажок сбрасывается: (1) при включении канала НЕ из этой группы (просто перейти курсором в другую группу — не сброс); (2) через 10 минут, когда ничего не играет — отсчёт с остановки видео или с ввода PIN, даже если остаёшься внутри группы; пауза считается просмотром; проверка раз в 30 с; (3) при запуске приложения / сворачивании. Пока играет канал этой группы, флажок держится, таймер стоит. После сброса колонка каналов этой группы сразу пустая, при входе снова PIN. Режим «По PIN» при этом не меняется.
- **Настройки:** вход без PIN. Режим группы меняется в окне из трёх вариантов (текущий отмечен `* `). Усиление — без PIN. Ослабление (Скрыта → любое, По PIN → Показана) — с PIN, один раз за заход. Если PIN не задан — сначала «Придумайте PIN-код» («Чтобы ослабить защиту, сначала придумайте PIN-код»); выбор «По PIN» без PIN — тоже. PIN, введённый или созданный в Настройках, ничего не открывает для просмотра.
- Изменить или удалить PIN — с текущим PIN или мастер-кодом. Удаление/сброс PIN: все группы «По PIN» → «Скрыта».
- **Мастер-код** (только сброс PIN): местное время ЧЧММ (24 ч) задом наперёд, 13:45 → 5431, принимается и предыдущая минута. Работает в любом окне ввода PIN, ведёт к окну «Сбросить PIN-код?». Настоящий PIN проверяется первым. Подсказка в окне ввода PIN (не в окне создания): «Забыли? Введите мастер-код» / «Forgot it? Enter the master code.» / «¿Lo olvidaste? Introduce el código maestro.» Описывается в карточке магазина.
- [Roku] PIN хранится как есть в реестре приложения; [LG] — хеш. ❓ вопрос 6.

## 8. Сворачивание
- [LG] поток останавливается; при возврате видео не возобновляется, если играл канал группы «По PIN».
- [Roku] кнопка Home закрывает приложение целиком, поэтому «сворачивание» = новый запуск.

## 9. Программа передач (EPG)
**Общее:**
- XMLTV по первой настоящей http(s)-ссылке из `url-tvg` / `x-tvg-url`. Загрузка через 1,5 с после старта картинки, обновление раз в 6 часов, ручное — пункт «Программа передач» в Настройках («N каналов, обновлена в ЧЧ:ММ»). Смена плейлиста — загрузка по его ссылке. Тайм-аут 180 с, устаревшие ответы игнорируются.
- Файл читается потоком, кусками; разбираются только законченные `<channel>` / `<programme>`, хвост ждёт следующего куска.
- Хранится окно «−2 ч … +24 ч», только каналы плейлиста; описания — у передач ближайших 4 часов, до 600 символов. Время `20261107030000 +0300` → UTC.
- Сопоставление: ключ канала = `tvg-id`, иначе `n:` + нормализованное название; сначала по id, затем по `display-name`. Каналы с одинаковым tvg-id делят программу. Атрибуты в двойных и одинарных кавычках.
- Показ: строка канала (передача + прогресс); третья колонка: «Сейчас» (название, «18:00 – 18:45», «осталось N мин», прогресс, описание до 7 строк), «Далее» — 4 передачи (8 без описания); без программы — причина (загружается / нет ссылки / не загрузилась / нет для канала); плашка плеера — передача и время. Перерисовка раз в минуту.
- Диагностика в журнале: часовой пояс; ответ сервера (код, тип, размер, сжатие, первые 200 символов); ход каждые 20 МБ; итог (МБ, мс, каналов, совпало по id/названию, передач всего/сохранено); отброшенное по причинам; при совпадении < 50 % — примеры id.

**[LG]** сделано: gzip (по `.gz` и байтам 1F 8B), кодировка из `<?xml encoding>` (в т. ч. windows-1251).
**[Roku]** сделано в 1.2.0: служба EpgService (Task) держит программу и отвечает сцене (передача в эфире по всем каналам раз в минуту; текущая + следующие для одного канала); чтение кусками по 4 МБ через HTTP Range, иначе через файл в `cachefs:`; результат кэшируется в `cachefs:/epg.json` (при запуске свежая копия < 6 ч берётся сразу); тайм-аут всей загрузки 300 с. **Ограничения Roku:** gzip-файл не поддерживается → понятная ошибка; windows-1251 — нет. Колонка 3 = играющий канал, иначе выделенный. Ручное обновление — строка «Программа передач» в Настройках.

## 10. Журнал
- Первая строка — название и версия. Ключи доступа никогда не попадают в журнал и на экран.
- Маскировка (одинаково): параметры `token, key, password, pass, pwd, auth, sid, session, signature, sig, username, user, login, mac` → `***`; `логин:пароль@` → `***@`; Xtream `/live|movie|series|timeshift|play/<логин>/<пароль>/` → `/***/***/`; сегмент пути 8+ символов из букв/цифр/`-`/`_`, где есть и буквы, и цифры → `***`; сегмент 24+ символов без точки (хеш) — `***` даже без цифр.
- [Roku] `telnet <ip> 8085`, выключается в config.brs. [LG] в памяти ТВ, 500 записей, «Настройки → Журнал»; в тексте кода не должно быть слов password/token/pwd (сканер LG).

## 11. Только для одной платформы
- **[Roku]** `rsg_version=1.3`, Roku OS 15.1+, монитор памяти, `AppLaunchComplete`, deep link (`contentId` = tvg-id или название, только показанные группы), правило автовоспроизведения, кнопка `*` не во время видео, пакет ≤ 4 МБ.
- **[LG]** выбор движка (встроенный webOS по умолчанию / hls.js 1.7.3), Magic Remote (указка и колесо), цветные кнопки, набор номера, `screenSaverProperties`, Back на стартовом экране по правилам LG, Full HD 1280×720, шрифт ≥ 20 px.

## 12. Открытые вопросы
1. ~~Сброс PIN~~ — решено (раздел 7): сбрасывается только введённый PIN, режим «По PIN» остаётся. LG выровнять под это правило.
2. **Нет ни кэша, ни сети при запуске:** [LG] пустой список, курсор на `> Плейлисты` + окно ошибки; [Roku] текст ошибки в колонке каналов, курсор на `> Плейлисты`. Предлагаю вариант LG.
3. **Имя текущего плейлиста:** [LG] в строке `> Плейлисты`; [Roku] над колонками. Выбрать одно.
4. ~~Название~~ — решено: **«ShaGa IPTV Player»** на обеих платформах (магазины, плитка, тексты, картинки, политика). LG: поменять `title` в appinfo.json и тексты; id `com.shaga.player` не меняется.
5. **Правило версий:** LG — MAJOR = публичный релиз; Roku — MAJOR = крупные изменения. Выбрать одно.
6. **PIN:** хранить хеш на обеих платформах (как LG).
7. **EPG на Roku:** какие файлы у ваших провайдеров — `.xml` / `.xml.gz`, UTF-8 / windows-1251 — и поддерживает ли сервер HTTP Range.

## 13. Что сделать, чтобы выровнять версии
**Roku → до LG 0.4.0:**
- сохранять новый плейлист только после успешной загрузки; окно ввода остаётся с ошибкой;
- курсор на текущем пункте в окнах «Плейлисты», «Язык», режима группы; `*` у текущего в «Язык»;
- загрузка плейлиста мимо HTTP-кэша (`Cache-Control: no-cache`);
- расширенная маскировка журнала (раздел 10);
- поиск пересчитывается при обновлении плейлиста (сейчас сбрасывается);
- пункт «О приложении / Политика конфиденциальности»;
- EPG (раздел 9) — отдельным этапом.

**LG → до Roku 1.1.0:** по сводке LG 0.4.0 расхождений, кроме открытых вопросов, нет; запланированное в LG 0.4.1 — требования LG Store.

## 14. Как ведём работу
- Архивы: Roku — `shaga-iptv-player-<версия>-roku.zip`; LG — `shaga-iptv-player-<версия>-lg.zip` (везде дефис). Файлы внутри — сразу в корне.
- К каждой версии: как установить, изменённые файлы для GitHub, название коммита до 50 символов и описание на английском, сводка для синхронизации.
